# DeepWriter 1.3.0 RC1

本次为 **Windows x64 未签名预发行版**，安装版与便携版可在下方 Assets 下载。正式受信任代码签名尚待配置，Windows 可能提示未知发布者；这次发行不宣称已完成正式签名。

## 下载

- `DeepWriter-1.3.0-x64-setup.exe`：安装版，适合日常使用。
- `DeepWriter-1.3.0-x64-portable.exe`：免安装版。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。

## 这次改进

- 未发送文字按会话自动保存，重启后继续编辑；退出等待保存，保存失败可以返回应用。
- 流式回复减少重复渲染；上翻阅读保持位置，点击“回到最新”继续跟随。
- 多行输入、窄窗口和生成期间保持可用；删除失败保留草稿，会话操作支持键盘。
- 修复旧任务错误影响新任务状态和初始化漏接快速回复的问题。

从 1.2.6 升级前，请退出应用并备份用户数据目录。升级保留历史、设置与凭据。草稿文字保存在本机数据库；附件重启后需重新选择。
