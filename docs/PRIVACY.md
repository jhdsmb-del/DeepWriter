# 隐私与本地数据

本文描述当前源码的主要数据路径。历史安装包的具体行为以对应版本文档为准。

## 模型请求

发送任务时，消息、系统指令、选定附件提取出的文本、工具结果和必要上下文会发送给配置的 Provider。模型服务可能保留请求并收取费用，具体由服务商政策决定。DeepWriter 没有替服务商承诺数据保留或零费用。

选择工作目录不等于把整个目录自动上传；Agent 的读取与搜索结果进入任务后可能作为后续模型上下文发送。不要在未经检查的工作目录中处理包含秘密的任务。

## 网页搜索和读取

联网搜索复用当前运行所选模型供应商的 API Key，仅连接该供应商的官方接口。不使用公共免密搜索。工具发送搜索词或要读取的公开网址，不把附件或整段对话附在检索请求上；模型生成的搜索词仍可能包含你提到的信息。处理敏感资料时，可点击地球图标关闭联网，或在 CLI 新任务加 `--no-web`。对话本身仍通过所选模型服务处理。

ZIP 在本机按需读取，不解压到工作目录，也不自动运行包内文件。发起对话时，目录和经过筛选的正文摘录会随任务发给所选模型；定点读取的内容也会进入模型上下文。提交前请先移除不打算交给模型的资料。

## 凭据

Provider 凭据保存在主进程，由 Electron safeStorage 与系统凭据设施加密。Renderer 获得配置与凭据状态，不获得注册表中的明文 Key。运行时使用冻结的 Provider 配置，凭据缺失或版本不匹配会停止并等待处理。

系统凭据存储不可用时拒绝持久化凭据。旧配置兼容路径中的临时内存 Key 不应视为正常 Provider 或跨重启恢复的替代品。日志、报告和截图不应包含 Key。

## 本地工具

文件读取、写入与搜索受路径和权限检查约束。写入使用同目录临时文件替换，并保留写前快照。读取与目录输出有上限；文本搜索跳过大于 2 MB 的文件，避免无界读取。

命令通过参数数组运行，受权限策略检查，但使用当前操作系统账户权限。工具授权不是操作系统级隔离，命令可能访问网络或产生应用无法回滚的外部副作用。

取消会停止后续处理并尝试终止命令进程树。已经完成的写入、网络操作或其他副作用不会因点击停止自动撤销。

## 数据存储

会话、运行、事件、用量与恢复信息存储在 userData 下的 SQLite 数据库及相应本地文件中。旧版本的 JSON/JSONL 数据可能在迁移后保留；风格、创作项目与快照还使用独立文件。

1.3.0 源码的未发送文字保存在本机 SQLite 草稿表中，退出前等待保存，重启可恢复；这些文字没有使用凭据加密。删除会话会删除对应草稿，发送被接受后只清除已提交内容。待发送附件引用保存在界面内存中，重启后需重新选择。1.2.6 及旧版本草稿只在运行期间保留。选择和预览附件会读取本地文件，发送后其提取内容可能进入模型请求。

Windows 常见位置为 `%APPDATA%/DeepWriter`。备份或迁移前退出应用并保存整个 userData 目录，并另行备份工作目录与导出文件。删除聊天或任务不能保证删除所有备份、导出文件或系统备份；如需完整清除，先确认副本和导出位置，再删除用户数据。

## 反馈与报告

问题反馈只需版本、平台、步骤和必要的脱敏日志。不要提交完整私人项目、用户数据目录或凭据。安全问题按 [SECURITY](../SECURITY.md) 的渠道报告。
