# 路线图

优先级围绕可靠的桌面 Agent。新能力应复用当前运行、权限与恢复流程，不能增加平行的事实源或重复配置入口。

## 当前阶段

- 收敛三个主要工作区，移除重复控制面板与误导性进度。
- 统一命令取消、超时和 Windows 启动路径。
- 为文件读取、目录输出和写入故障建立明确边界。
- 整理开发入口与用户文档，保留可追溯的版本记录。
- 对话优先，工具过程默认折叠；合并输入区配置，移除自动展开的运行侧栏。
- 保留会话草稿，隔离异步附件结果，避免重复发送与旧设置覆盖新凭据。
- 为工作区和弹层加入简短动画，遵循减少动态效果；Markdown 和任务详情按需加载。

## 1.3.0 发行候选

- 跨重启文字草稿、退出保存与失败重试，维持发送和删除的原子边界。
- 流式显示合批、已有消息复用，上翻阅读时停止自动跟随。
- 实际 Windows 全新安装、1.2.6 升级、凭据解密与卸载保留验收已通过，结果见 [验证记录](VALIDATION.md)。
- 受信任代码签名与时间戳验证，缺少签名资源时阻止正式发布。

## 优先完成

- Windows 干净安装、升级、退出与跨重启恢复的发行验收。
- 凭据存储失败、授权等待、未知副作用与用量缺失的完整桌面回归。
- 首屏加载、较大工作目录和长消息的资源测量，按证据减少开销。
- 保持单一事件与恢复事实源，逐步拆分过大的主进程模块。

## 随后改进

- 在稳定行为上整合历史测试命令，减少维护成本。
- 文件搜索的索引与编码支持，清晰呈现跳过的文件。
- 次级创作工具与 Agent 的合同、进度和结果展示保持一致。
- 用真实 Provider 做成本、长时间运行与模型质量评测，记录失败而非只展示成功示例。

平台扩展与更多工具应等可靠性和发行验收稳定后再推进。路线图不是已发布能力或时间承诺。
