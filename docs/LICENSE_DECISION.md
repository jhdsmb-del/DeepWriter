# 许可证

项目自有代码采用 [MIT 许可证](../LICENSE)。

## 项目自有代码

MIT 授予获得软件副本的人使用、修改、分发和商用等权利，要求保留版权及许可声明。

此决定适用于项目自有代码，不替换第三方库、Electron/Chromium、字体、图像或用户导入素材的许可。新旧发行包需分别保留所含资源的原有许可与必要通知。

## 分发检查

依赖清单与通知检查需覆盖传递依赖和实际打包资源，区分锁文件计划、当前平台安装内容与真实制品内容。未知许可、缺少原文或版本不匹配应列为待复核，不能仅凭 package.json 的许可名称宣称法律兼容或完整合规。

历史 status.json / STATUS.md 中的许可待定条目属于旧评审基线，不是本决定后的当前状态。此前候选比较与未决记录保留在 Git 历史，不作为现在的授权结论。

许可参考：[GitHub 许可说明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)、[MIT 文本与条件](https://choosealicense.com/licenses/mit/)。正式商业授权条款或依赖兼容问题需要时应交由专业人士审核。
