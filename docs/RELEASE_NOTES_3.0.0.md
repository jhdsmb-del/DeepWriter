# DeepWriter 3.0.0

桌面与 CLI 使用同一套运行引擎。「Agent」用于查资料、处理文件和执行任务；「长文」用于先定大纲、再连续成稿。

## 桌面

打开就是「今天想写什么？」。直接输入任务，或选「起草文字」「查资料」「处理文件」。侧栏可以搜索历史会话和草稿；离开长文工作区再回来，未发送的构想还在。

新 Agent 任务默认开启联网搜索。点输入栏的地球图标即可关闭。支持工具调用的模型可以搜索公开网页、读取来源，在工作目录内使用现有文件和命令工具。旧任务恢复时沿用原来的工具范围。自定义模型可在「规格与连接」里单独测试工具调用，不用靠模型名字猜。

## 长文

正文跨场景续写时，已接受的段落与尚未写完的句子分别保存。达到篇幅后仍会补齐自然结尾再导出。审校可以读取代码围栏中的有效结构化回复，不会把格式外壳当成内容错误。确需作者判断的冲突仍保留草稿和原因。

## 终端

```powershell
.\cli\deepwriter.cmd agent "读一下项目说明，列出三件最值得先做的事。" --work-dir .
.\cli\deepwriter.cmd chat --input brief.txt --output reply.md --no-web
.\cli\deepwriter.cmd export RUN_ID --output final.md
```

`--input` 和管道适合接长任务。指定 `--output` 时，只写完成的正文，不把中途的流式片段混进文件。`export` 从本地已完成的运行取稿，不调用模型。原有的同名文件不会被覆盖。

## 安装

完整解压 ZIP：`desktop` 里有安装版和免安装版；`cli\deepwriter.cmd` 自带 Node 运行时。桌面升级沿用原有数据目录。两端的配置和历史仍独立保存。详见[快速开始](QUICKSTART.md)和[终端指南](CLI.md)。
