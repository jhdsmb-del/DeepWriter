# DeepWriter 1.3.4

本次更新集中改善模型供应商的配置与导入。

- 添加供应商时填写名称、Base URL、API Key、API 格式和模型 ID，一次保存即可选择模型。
- 已添加供应商的 URL、Key 和 API 格式可直接修改；“保存配置”与“保存并关闭”均会提交修改。
- Key 留空保留原配置，输入新 Key 即可替换。编辑中的内容不会被列表刷新覆盖。
- 常见模型自动补齐上下文、最大输出和思考选项，已有模型也可读取规格。
- 模型列表按需展开“规格与连接”，可查看规格或发送一条短请求测试连接。
- 简化默认界面，详细参数放在高级设置中。

## 使用

打开“设置 → 模型与接口”。选择已有供应商进行修改，或点击“添加供应商”。Base URL 可直接粘贴带 `/v1` 的地址；按服务商选择 API 格式，填写模型 ID 后保存。

Windows x64 提供安装版和免安装版。升级前关闭旧程序，安装新版或使用新的免安装文件；会话、配置与稿件继续保留。
