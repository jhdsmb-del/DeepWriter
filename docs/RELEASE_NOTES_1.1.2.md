# DeepWriter 1.1.2

这是 1.1.1 的可用性热修，重点处理 Ren'Py SDK 识别和工作流管理。

## Ren'Py SDK

- Galgame Studio 现在直接提供“自动扫描”“选择 SDK 目录”“下载官方 SDK”三个入口。
- 自动扫描下载、文档和桌面中的常见 `renpy-x.y.z-sdk` 目录，支持两层目录结构。
- 手动选择后立即运行真实 `--version` 验证；通过后保存命中路径，并显示在工作台状态中。
- 设置页改为选择 SDK 根目录，不再要求用户定位到 `renpy.exe`。

## 工作流

- 修复非当前运行无法从工作流侧栏停止的问题；取消请求现在进入真实运行内核并持久化为已停止。
- 最近结束列表同时展示完成、失败和停止记录，并提供带确认的“删除工作流”。
- 删除会清理流程事件、账单、运行证据和活动快照，但保留聊天会话。
- 工作流侧栏可以正常关闭，入口仍保留。
- 主窗口右上角关闭现在代表退出应用；最小化才会继续使用悬浮窗。

## 验证

- 本机 Ren'Py 8.5.3：自动发现、手动选择、`--version` 和真实 lint 均通过。
- 工作流关闭、停止、删除桌面回归通过。
- Windows 生命周期六状态：28/28 通过。

> 当前 Windows 制品未购买代码签名证书，首次运行可能出现 SmartScreen 提示。
