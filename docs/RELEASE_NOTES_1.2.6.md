# DeepWriter v1.2.6 Beta

更简洁的桌面 Agent，更顺畅的日常对话。

## 这次更新

- 对话优先展示回复，工具过程按需展开；常用设置集中到输入框旁，移除重复导航与自动展开的运行侧栏。
- 页面切换、弹层进出和按钮反馈更轻柔；支持快速重开、键盘焦点返回和系统减少动态效果。
- 会话切换保留未发送文字和附件，发送失败保留草稿；避免重复发送和异步附件串入其他会话。
- 修改目录和设置时保留较新的模型与凭据；修复工具过程中的空结果、执行失败和退出码显示。
- 长文连续没有有效正文进展时及时暂停，避免反复调用模型；场景修复仍使用独立的次数上限。
- 长文上下文只读取需要续写的已接受正文尾部，减少历史越长每轮越慢的问题；保留正文哈希、缓存失效和未完成正文校验。
- 修复中文场景 ID 导致长文提交失败的问题，保留来源、哈希和恢复边界校验。
- 修复 Windows 带引号的命令路径，保留目录分隔符、空格和网络共享路径；权限判定与执行继续使用同一解析规则。
- 改进文件读写、命令取消和超时处理；较重界面按需加载，首屏 JavaScript 入口比 1.2.5 基线减少约 49.7%。

## 下载与升级

- `DeepWriter-1.2.6-x64-setup.exe`：Windows x64 安装版。
- `DeepWriter-1.2.6-x64-portable.exe`：Windows x64 免安装版。
- `SHA256SUMS.txt`：下载文件的校验值。

升级前退出旧版本并备份重要数据。会话、设置和任务记录沿用原有 userData；未发送草稿只在当前运行期间保存，不跨重启恢复。免安装版同样使用本机用户数据目录。

## 验证与状态

此版本沿用 Beta 状态。发布流程在 Windows 上运行源码回归、发行专项检查、桌面 E2E、ASAR 检查和打包后 E2E，全部通过后才公开安装包；构建来源与文件校验随 Release 提供。

本地 Linux 桌面回归连续两次各 111 项通过，最终 v1.2.6 打包程序的 113 项回归通过，使用真实 Electron、实际文件工具和本地模拟模型。模拟测试不代表真实 Provider 的质量或费用。安装/升级/卸载的完整人工矩阵、长时间运行和人工无障碍验收仍需进一步验证。

安装包尚未提供商业代码签名，Windows 可能显示安全提示。稳定发行版仍为 v1.1.2；macOS、Linux 和 ARM64 安装包不在本次发布范围。
