# DeepWriter 3.0.2

选好稿件目录后，把任务直接交给 Agent：

- **「只改第 5 行的称呼。」** 如果同一句原文出现多次，工具会给出行号，不会默认改第一处。
- **「把《河岸》里的小曲全部改为小禾。」** 全文替换后，回执给出实际修改次数和原稿行号。若作者在修改准备期间另存了新稿，Agent 会收到重读提示。
- **「把预算改成 `$150`，其余不动。」** 替换文字按字面写入，包括 `$&`、引号和反斜线。可直接修改 UTF-8 稿件；原稿未选中的换行、空行和 BOM 保留。

**回看改动。** 在桌面当前回复下展开「查看过程」，点开编辑工具，即可查看修改前后的摘录。终端交互输入 `/changes` 看当前会话；`deepwriter changes RUN` 只看指定任务，支持 `--json`。这是已完成的文件工具记录，不是当前目录的 Git 差异。
