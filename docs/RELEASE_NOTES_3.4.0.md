# DeepWriter 3.4.0

## 一起读几份文件

选择工作目录，输入「找出所有大纲，读前三份，比较第二章的人物设定」。桌面与 CLI 的 Agent 现在能按文件名或相对路径查找，也能用一次工具调用批量读取。每份结果仍标出来自哪个文件，便于对照原文。

## 直接看速度和缓存

生成时，输入框下方显示 **tok/s · 缓存命中**。「≈」表示流式采样的估算值；结束时若服务商返回输出 token 数，就按整个请求耗时显示平均值。缓存命中率来自当前请求的服务商用量；没有数据就显示「—」。切换会话不会沿用上一段回复的数字。

流式输出不再等待固定间隔的轮询。密集小片段合并传给界面，长文显示也不必为每次字符计数复制整段正文。服务商的出词速度和客户端处理时间分别衡量。

## 上下文跟随模型

换模型后，新任务自动采用该模型的窗口和输出预留，不用再选择上下文模式。模型配置中录入的自定义规格、固定事实和固定消息仍然有效。不同写作阶段使用不同模型时，各阶段按自己的模型安排输入。未提供窗口规格的模型采用保守默认值。

连续追问时，已有历史保持原顺序，新问题排在最后。这样既不会把今天的追问夹进前面的对话，也让服务商有机会直接复用相同的请求前缀。
