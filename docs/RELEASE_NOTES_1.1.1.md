# DeepWriter 1.1.1

1.1.1 让任务状态和费用更容易看懂，并补齐 Galgame Studio 从素材到真实 Ren'Py 校验的最后一段操作闭环。

## 更直观的任务详情

- 账单第一屏直接显示总费用、输出量、总耗时和本地工具次数。
- 费用按“生成与任务编排”“审校与修订”“工具执行”拆分；工具在本机运行，不伪造额外模型费用。
- token 分成输入、生成文本、模型推理、缓存命中和缓存未命中。
- 阶段耗时改为比例条，Provider 请求和上下文清单保留在折叠审计区。
- 活动页新增真实事件驱动的流程图，并突出当前正在执行的阶段。

## Galgame Studio 完整闭环

- 入口展示项目、SDK、素材、Grill Me、大纲与分支、制作、lint/修复、完成八个阶段。
- 大纲确认页展示章节预算和现有 Ren'Py 分支关系。
- SDK、素材、当前模型、思考强度和 Agent 预设继续使用主进程冻结的可信配置。
- 缺少模型或凭据时生成的骨架不再被判定为完成；必须由剧情 Agent 真实写入内容。
- lint 错误可生成修复 diff，用户确认应用后自动用官方 Ren'Py 8.5.3 重新检查。
- 项目目录可从 Studio 直接打开。
