## 有证据的性能变化

与 `584e6ab`（1.2.5）使用相同依赖和构建命令比较，1.2.6 Renderer 首屏入口从 1,643,115 bytes 降至 827,238 bytes，减少 49.7%。设置、长文、创作工具、Markdown 和运行详情按需加载；这是入口文件变化，不代表总安装包、启动耗时或内存下降。

1.2.6 长文上下文改为读取选中的已接受正文尾部。同一 Linux 环境、Node.js 22.23、2,000 个千字片段及 240 次实际 ContextService 采样，p95 从 145.788 ms 降至 20.095 ms，减少约 86.2%。这是本地上下文组装耗时，不代表模型生成速度。尾部外的已接受正文修改仍使缓存失效，未完成正文篡改仍会阻止请求。

1.3.0 的短时间文字更新合批减少重复渲染；回归证明正文和事件顺序不变。尚未测量帧率、整机内存或启动速度，不作对应性能承诺。
