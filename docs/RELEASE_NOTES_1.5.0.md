# DeepWriter 1.5.0

DeepWriter 是 Windows 文本写作助手。完整包包含桌面安装版、免安装版和同版本 CLI。

## 本版变化

- **对话更直接。** 自定义模型填入服务地址、Key 和模型 ID 即可使用；没录入目录的型号也能发送，参考价缺失不再挡住对话。
- **停止后可以继续工作。** 已保存的稿件保留，输入框恢复可用；结果尚不明确的工具操作留在任务详情里供你处理。
- **CLI 支持连续对话。** 用 `/new` 新建、`/sessions` 查看会话、`/session` 切换会话、`/model` 选模型。按 Ctrl+C 停止当前生成后回到输入提示符。
- **CLI 配置与服务地址一致。** 常见 Base URL 可直接粘贴；切换 API 格式时会更新默认请求路径和认证头。

## 开始使用

完整解压后，在 `desktop` 目录运行安装版或免安装版。打开“设置 → 模型与接口”，添加服务商和模型，再回到输入框选模型发送。CLI 运行 `cli/deepwriter.cmd`，无需另外安装 Node.js。

升级前请关闭旧程序。已有桌面会话和配置沿用原数据目录；CLI 继续使用原来的数据目录。详见[桌面指南](QUICKSTART.md)与[CLI 指南](CLI.md)。
