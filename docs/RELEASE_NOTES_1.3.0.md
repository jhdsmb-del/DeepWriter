# DeepWriter 1.3.0

本版本聚焦可靠的桌面对话体验。[1.3.0 RC1](https://github.com/qlys123/DeepWriter/releases/tag/v1.3.0-rc.1)已发布 Windows x64 安装版与便携版，明确标注未签名预发行版；[Windows 完整安装验收](https://github.com/qlys123/DeepWriter/actions/runs/36917547819)及[发布后下载校验](https://github.com/qlys123/DeepWriter/actions/runs/36949710902)通过。正式 Windows Release 仍等待受信任代码签名。

## 日常体验

- 未发送文字按会话自动保存到本机，重启恢复最后编辑的草稿，切换会话可继续编辑。
- 退出前等待草稿保存；保存失败会保留窗口中的文字，提供重试，并允许返回应用处理。
- 发送确认只清除已提交文字，保留等待期间新写的下一份任务；删除会话同时删除草稿。
- 流式回复合并短时间内的文字更新，已有消息与导航减少重复渲染；保留原始正文、工具与终态顺序。
- 长回复跟随新内容，上翻阅读时保持位置；点击“回到最新”恢复跟随。生成期间保留输入焦点和下一份草稿。
- 多行输入与窄窗口下，“回到最新”保持在聊天区域内；会话删除失败保留窗口文字和持久化草稿，提供明确提示。
- 会话操作支持键盘聚焦显示；保持短动画并尊重系统减少动态效果。
- 修复旧任务迟到的错误清除新任务运行状态，以及初始化期间可能漏掉快速回复事件的问题。

## 升级与数据

从 1.2.6 升级前先退出应用并备份整个用户数据目录。数据库新增独立草稿表，迁移保留会话、任务、凭据与原有恢复记录；不会把未发送文字当成聊天或已执行任务。

草稿文字保存在本机数据库中，不属于加密凭据。附件引用只在本次运行期间保留，重启后需重新选择。草稿上限为每份 200,000 UTF-16 单元、200 份非空草稿、总计 20 MiB UTF-8 文字；达到上限时保留窗口输入并提示保存失败。
