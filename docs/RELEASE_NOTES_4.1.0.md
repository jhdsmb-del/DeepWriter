# DeepWriter 4.1.0

## 普通 Agent 可以接着做

把三份交接记录放在工作目录，试试：「逐份核对柜号，列出冲突，再按负责人整理待确认项。」对于这样的多步任务，Agent 可以列出任务清单，在桌面活动或任务详情中查看；简单对话不用先列计划。CLI 使用同一份进度：

```powershell
deepwriter agent "核对这三份交接记录，列出冲突，再按负责人整理待确认项"
deepwriter status RUN
```

将 `RUN` 换成上一步的任务 ID。关闭程序后也能查到最近一次有效更新。有未完成项而模型提前停笔，程序会提醒一次，接着做下一项；如果确实缺资料或权限，会留下等待原因，不会把任务标为完成。任务清单只描述进度，不能代替实际文件或授予操作权限。

## 长对话保留早期要求和后来更正

比如最初要求「只能离线、保留 CSV」，中途又把 SQLite 改成 DuckDB。对话超过模型窗口时，DeepWriter 会在本地按会话整理关键原话，带上先后顺序，给近期完整对话留位置。新要求优先；重新打开一个旧任务，不会把此后才发的消息倒灌进去。整理记忆不另发模型请求。

## 读多份资料、改一段原稿

同一轮读不同的本地纯文本时，最多同时读四份；需要授权的步骤、写入与命令仍按先后顺序执行。读取结果的顺序与模型提出的请求一致。

模型粘贴原句时，如果引号或空白和原稿不同，编辑工具现在会给出实际行段和原文供它重试。不会直接做模糊替换，也不会顺手把全稿的标点和换行改掉。
