# DeepWriter v1.2.5 Beta 使用说明

> Windows x64 · 构建日期 2026-10-01 · 源码提交 `4162ff5f26f60f5ffe4b170e3aa64366ed474818`

DeepWriter 是一款本地桌面写作 Agent。它把普通对话、长文创作和 Galgame / Ren'Py 制作放在同一个工作台里，并记录工作阶段、模型调用、Token、费用、耗时和文件产物。

本次交付是 **v1.2.5 Beta**。它适合试用和继续验收，不代表稳定版、RC 或正式发布版。

## 首次设置

1. 打开右上角设置，在“模型与接口”中添加 Provider、API Key、Base URL 和模型。
2. 在“文件与目录”中选择文档目录和工作目录。长文完成后会把 Markdown 稿件写入文档目录；Agent 工具只在已授权的工作目录中操作。
3. 在输入框左下角选择模型和思考强度。正在运行的任务会冻结当前配置，不会在中途漂移。
4. 根据任务选择“完整 / 优化 / 精简”上下文档位。优化档会保留来源、摘要和最近窗口，适合长对话节省 Token。
5. 如有固定写作要求，可在显眼的“预设提示词”入口添加；它同时适用于下一次普通对话和长文任务。

内置原生协议包括 DeepSeek、OpenAI Responses 和 Anthropic Messages；另有 Gemini、xAI、Qwen、GLM、Mistral、SiliconFlow 等兼容预设，也可以自行填写协议、地址、认证 Header 和模型名。密钥优先使用系统安全存储；安全存储不可用时不会写入导出文件。

## 普通对话

在顶部选择“Agent”，输入任务后发送即可。附件会先在本地解析，只有在任务需要且得到授权时才作为上下文发送给模型。

运行中可以：

- 在消息区或任务详情中查看当前动作；
- 在“任务中心”查看模型输出、工具调用、文件产物、Token、费用和耗时；
- 点击顶部悬浮窗按钮，把当前项目名和阶段留在桌面上；
- 点击“停止”终止当前任务。

## 长文写作

长文不是要求模型在单次回答里硬写完全部字数。DeepWriter 会先梳理需求，再按大纲和场景连续推进，直到达到完成条件或遇到真实阻塞。

推荐流程：

1. 切换到“长文”，填写题材、主题、目标篇幅、人物、视角、禁项和希望保留的表达方式。
2. 启动后先进入 **Grill Me**。每轮回答一个问题，可以选已有选项，也可以在下方补充自由文本。
3. 信息充分后检查大纲和预计篇幅；只有确认大纲，正文才会开始。
4. 正文会按场景自动接续。默认强约束会检查主题、人物、视角、事实和禁项，发现偏移时优先局部修订，而不是整篇推倒重写。
5. 在右侧活动抽屉或“任务中心”查看它当前正在规划、生成、检查、修订还是写入文件。
6. 完成后会在已设置的文档目录生成 Markdown 稿件。任务详情的“产物”区域显示路径、实际字数，并可直接打开文件。

目标篇幅支持从短文章到大规模长文。实际执行会受模型上下文、单次输出限制、账号速率和预算影响；这些情况会显示为明确的等待、预算或授权状态，不应把未完成稿误报为完成。

如果任务中断：

- 在长文工作台的“待处理任务”中点击“继续”；
- 需要人工判断时，先打开“复核”；
- 不再需要时点击“停止”；
- 任务进入终态后，在任务详情底部点击“删除工作流”。运行中的任务必须先停止才能删除。

## Galgame / Ren'Py

1. 切换到“Galgame”，新建工程或导入包含 `game/` 的现有 Ren'Py 工程。
2. 在环境检查中点击“自动扫描”，或手动选择包含 `renpy.py` 与 `lib/` 的 SDK 根目录；本机没有 SDK 时可点击“下载官方 SDK”。
3. 添加人物设定、立绘、背景、音乐和音效，并先处理素材检查提示。
4. 进入 Grill Me，确认故事目标、角色关系、关键事件和分支，再确认大纲。
5. 生成剧情节点和补丁，查看改动后执行真实 Ren'Py lint；写入并通过检查后才算完成。

当前项目已经用真实 Ren'Py 8.5.3 路径做过门禁验证，但不同工程的自定义 Python、插件和资源仍需在你的机器上实际运行确认。

## 任务、账单与悬浮窗

“任务中心”是统一的运行记录入口：

- 活动流按时间显示规划、模型、工具、文件、权限和错误事件；
- 账单按生成/编排、审校/修订和本地工具分类；
- Token 明细区分输入、输出、缓存和推理用量（以 Provider 实际返回为准）；
- 耗时显示任务总时长和各阶段耗时；
- 运行时可打开悬浮进度窗，显示项目名、自然语言阶段和停止按钮。

Provider 没有返回可靠用量或价格时，应用会标记为未知，而不是伪装成 0。

## 数据位置与备份

- 会话、设置和运行记录默认保存在 `%APPDATA%\DeepWriter`。
- 长文稿件写入你在设置中选择的文档目录。
- Galgame 文件写入你创建或导入的 Ren'Py 工程目录。
- 升级或卸载前，建议备份重要稿件、工程、素材和 `%APPDATA%\DeepWriter`。

安装版和便携版默认使用同一套应用数据。若要隔离测试，请先备份数据，并使用单独的 Windows 用户环境或明确分开的工程目录。

## 常见问题

### 为什么长文没有立即开始写？

长文默认先完成 Grill Me 和大纲确认。这样能减少“输入很短、正文很长”造成的主题漂移。若界面仍在追问或等待确认，先完成当前问题或确认大纲。

### 为什么长文暂停了？

打开任务详情查看原因。常见情况包括 API 授权失效、上下文超限、预算不足、语义复核、Provider 限流或网络失败。修正后使用“继续”，不要重新创建同一任务。

### 为什么检测不到 Ren'Py？

在 Galgame 的环境检查中使用“选择 SDK 目录”，选择同时包含 `renpy.py` 和 `lib/` 的 SDK 根目录，而不是某个游戏工程目录。

### 如何关闭悬浮窗？

悬浮窗右侧的关闭按钮只隐藏窗口，不会停止任务；需要终止任务时点击悬浮窗或主界面的停止按钮。

### 如何彻底删除工作流？

先停止任务，等状态变为“已停止 / 已完成 / 失败”，再进入任务详情并点击“删除工作流”。这只删除运行记录，不等于删除已生成的稿件或 Ren'Py 工程。
