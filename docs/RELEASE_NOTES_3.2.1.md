# DeepWriter 3.2.1

## 模型连接

修复桌面版和 CLI 调用模型域名时的“无效 IP 地址”错误。此前请求可能在到达服务商之前中断，重新填写 Key 也没有用。

首次使用官方 DeepSeek，只需在「模型与接口」的内置 DeepSeek 页填 Key，点「保存配置」就可以回到聊天，不必再选一次默认模型。在设置里修改 Key 或地址后，测试连接与聊天使用该供应商的配置。不同供应商的 Key 分开保存；修改模型参数时，可留空保留原 Key。可信的本地服务可以明确选择免密，而不必填写占位 Key。

如果对话失败，先看服务商返回的状态：401 表示未通过认证，403 表示拒绝访问，402 表示账户余额或配额问题，429 表示请求受限。网络连接失败不代表 Key 无效。

## 写作与制作

风格写作、小说生成与修订、Galgame 剧本生成和修复，现在都使用相应阶段选中的供应商。可以用一个模型写、另一个模型审，不需要在旧版 DeepSeek 设置里再填一次 Key。

CLI 的默认环境变量只给官方 DeepSeek 使用。连接其他服务时，用 `--key-env` 指定为它准备的变量；本地服务不需要认证时，不会再收到一个空的 Bearer 头。
