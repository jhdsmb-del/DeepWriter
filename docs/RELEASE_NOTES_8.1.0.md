# DeepWriter 8.1.0

**工作模式可以跨文档查原话了。** 指定一个资料目录，让 Agent 在 Word、Excel、PowerPoint、EPUB 和文本文件里找一句话；用桌面版还可以搜 PDF 文字层。找到后，它可以继续读上下文，你也能在桌面回复的「文件来源」里核对摘录。没有文字层的扫描件不会被当成「没有这句话」。

完整包里有个两分钟的小例子。把 `examples/east-bank` 选作工作目录，然后问：

> 末班船原定几点，改到几点，实际几点离岸？分别引用班次单和值班簿，不要把计划当成实况。

**长任务中途改要求也更轻了。** 正在做事时发一句「只改小标题，正文别动」，Agent 仍会等当前工具返回再执行；接收这句话和刷新任务清单，不再需要搬运之前所有的对话和工具输出。

已有 8.0.0 安装版，请打开 **设置 → 应用更新**。使用终端的用户可运行 `deepwriter update check`。
