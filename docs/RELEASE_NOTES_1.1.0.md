# DeepWriter 1.1.0

DeepWriter 1.1.0 聚焦长文闭环、模型控制和 Galgame 制作流程。长文默认先完成 Grill Me 采访与大纲确认，再由编排器持续续写、检查、修订并生成稿件文件。

## 本版重点

- 长文目标扩展到 2,000,000 字，并按目标、模型单轮能力和上下文预算动态规划；短响应会自动接续。
- 完成状态同时受字数、自然句末、强约束和稿件文件约束，不再把单轮 `stop` 当作全文完成。
- 输入区左下角统一提供模型、思考强度和上下文范围；Provider、模型与 Profile 可在设置中管理。
- Agent 预设提示词统一进入普通对话、Grill Me、大纲、长文和 Galgame 生产链，并在任务启动时冻结。
- 工作流详情提供请求级 token、耗时、缓存命中和费用估算；悬浮窗只显示项目与自然语言状态。
- Galgame Studio 支持创建或导入项目、人物与素材录入、Grill Me、大纲/分支确认、官方 Ren'Py 8.5.3 SDK 下载校验、真实 lint 与修复闭环。
- UI 精简并统一下拉控件、字体、颜色和响应式布局；800 / 1024 / 1280 像素视口均完成桌面检查。
