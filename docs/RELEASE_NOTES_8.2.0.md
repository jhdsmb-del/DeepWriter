# DeepWriter 8.2.0

在普通 Agent 里勾选 **Goal 模式**，写下你希望交付的结果。比如：「根据渡口的班次单和值班簿，写一份更正通知，存成 通知.md，不改两份原件。」Agent 会先说明要做到什么，再按目标执行和核对；光有一段“已经写好”的回复不能代替文件。

再勾选 **不提问，自主执行**，就可以把普通取舍和项目工具授权交给它。可以免确认读写选定项目的普通文件、导出文档、执行已授权命令。联网沿用原设置，授权不带到下一条任务。中途仍能补充要求或停止；如果遇到真实障碍，查看任务里留下的原因。

终端使用 `deepwriter agent --goal "你的任务"`。要自主运行，加 `--no-questions`。已有安装版可通过 **设置 → 应用更新** 升级。
