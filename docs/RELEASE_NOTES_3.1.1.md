# DeepWriter 3.1.1

如果 Agent 把《河岸》里的“小曲”统一改为“小禾”，读过之后你还是更喜欢原名，现在可以只撤销这次改名。不用再发一条消息，也不必倒退整个会话。

**桌面：** 展开当时回复里的「查看过程」，点开文件的修改记录，对照原文和改文，再点「撤销这次改稿」。成功后记录会显示「已撤销」。关掉应用、下次回来，仍可查看。

**CLI：** 用 `deepwriter changes RUN` 列出这次运行的修改，复制对应的 `undo-edit RUN TOOL` 命令即可。查看和撤销都在本地完成，不用配置模型或 API Key。

**如果文件又被改过：** DeepWriter 会保留现稿。同一个文件有多笔 Agent 修改时，从最新一笔开始撤销。有完整记录的新改稿才提供撤销；旧记录仍可查看。
