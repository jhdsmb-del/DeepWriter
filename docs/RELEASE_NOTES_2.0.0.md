# DeepWriter 2.0.0

DeepWriter 是 Windows 文本写作助手。一个完整包同时提供桌面安装版、免安装版和 CLI。

## 工作区更简洁

- 导航和常用操作用统一的线条图标。移除重复说明和小字注释，任务状态、错误和账单按正常字号显示。
- 输入框底部只显示模型名称。点击可换模型或调思考强度，设置中可添加现有服务商或自定义 API。
- 长文按步骤逐问、确认大纲、写正文。停止任务后保留已保存的稿件；需要处理的运行可从任务中心打开。

模型配置导入会指出重复项和找不到的引用，不再静默丢弃。调用数、Token 和费用限制使用同一套预算规则。

## CLI 可以连续对话

直接运行 `cli/deepwriter.cmd`。用 `/new` 新建会话，`/sessions` 查看列表，`/session ID` 切换，`/model ID` 更换后续对话的模型。生成时按 Ctrl+C 暂停并回到提示符。

## 下载后怎么用

完整解压。桌面程序在 `desktop` 目录，CLI 自带 Node.js。桌面打开“设置 → 模型与接口”，保存服务地址、API Key 和模型 ID，回到输入框选模型即可。

若已安装旧版，先关闭旧程序再升级。桌面沿用原有数据目录；CLI 使用原来的数据目录。详见[桌面指南](QUICKSTART.md)和[CLI 指南](CLI.md)。
