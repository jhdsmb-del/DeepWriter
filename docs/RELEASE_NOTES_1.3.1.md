# DeepWriter 1.3.1

桌面与 CLI 共用同一套任务、写作和恢复引擎。1.3.1 简化日常入口，完善从需求澄清、大纲确认到连续写作、审校和稿件交付的流程。

Windows x64 完整包提供安装版、免安装版和同版 CLI；下载与源码运行方法见[仓库首页](../README.md)。

## 日常使用

- 输入框底部只显示模型名称。展开后调整思考强度或切换模型；上下文、Provider 和参考价放在二级设置。
- 统一菜单、焦点和短动画，保留键盘操作与系统减少动态效果的设置。
- 窗口最大化时，输入框与消息区域随可用宽度展开；正文保持适合阅读的行长，字体与按钮不会被拉伸。
- 长文逐问澄清需求，回顾事实与假设，再确认大纲。正文按场景自动推进、审校和收尾，不要求逐段点击“继续”；需要人工审阅、等待授权或额度不足时暂停。
- 草稿漏掉明确的场景动作时，自动修订并重新审校；事实不明或仍需修改时保留原稿和审阅入口。
- 完成状态对应真实稿件文件和内容哈希；未完成的正文保留为半成品。恢复不会扩大原预算、换模型，或覆盖用户修改过的同名文件。
- 修复多场审阅的版本冲突、审批后工作流投影，以及重启后原审批证据的恢复；陈旧或不匹配的审批仍会被拒绝。
- 未确认大纲可重新规划，失败时保留上一版大纲和采访信息。
- 改善审校格式异常与中断恢复：可恢复的格式错误在原额度内纠正一次；恢复保留原候选、审校记录和剩余额度，调用记录不明时暂停处理，避免重复请求。

## 独立 CLI

- 持续对话、工作目录与工具授权；逐问采访、大纲确认、连续正文和稿件交付。
- 查看会话、任务、用量、审阅与恢复记录。Ctrl+C 暂停并保存，取消是终态。
- 与桌面同版本，但独立保存配置、历史和凭据，不自动读取桌面 API Key。
- 完整包附带 Node 运行时和许可证，保留整个 `cli` 目录即可运行。完整解压后用 `.\cli\deepwriter.cmd --version`、`.\cli\deepwriter.cmd --help` 检查入口；命令与密钥配置见 [CLI 指南](CLI.md)。

## 模型与扩展

- 增加常用 Provider 配置预设、模型发现和自定义模型信息。支持 DeepSeek、OpenAI Chat/Responses、Anthropic Messages 协议，请按服务商接口和账户选择模型。
- DeepSeek 原生思考强度为低、高、最高；兼容旧配置时保留原任务身份，选项按模型能力提供。
- 用户可录入有来源的参考价。缺失用量或价格显示未知，不算成零；参考价不是服务商账单。
- 扩展目录提供第一方写作技能与稿件检查工具，默认关闭。安装、启用、选择与工具启动授权分别处理；停用或移除会撤销执行许可。
- 当前不提供任意第三方可执行插件、远程社区下载或完整协议版本兼容。详见 [扩展说明](EXTENSIONS_RESEARCH.md)和 [Provider 说明](PROVIDER_EXPANSION_RESEARCH.md)。

## 下载与升级

Windows x64 [完整 ZIP](https://github.com/qlys123/DeepWriter/releases/download/v1.3.1/DeepWriter-1.3.1-complete.zip) 包含安装版、免安装版、同版本 CLI、离线指南和[SHA-256 清单](https://github.com/qlys123/DeepWriter/releases/download/v1.3.1/DeepWriter-1.3.1-complete.zip.SHA256SUMS.txt)。仓库保持私有，下载需要有访问权限的 GitHub 账户：

```powershell
gh auth login --web
gh release download v1.3.1 --repo qlys123/DeepWriter --dir .\downloads\1.3.1
```

核对该版本的 SHA-256 清单后完整解压，打开 `desktop` 中的安装版或免安装版。CLI 自带运行时，无需全局 Node/npm；保留整个 `cli` 目录，在解压目录运行 `.\cli\deepwriter.cmd --help`。

升级前正常结束任务并备份完整数据目录与外部稿件；勿只复制数据库或混合两套数据。参阅 [首次使用](QUICKSTART.md)、[操作与恢复](OPERATIONS.md)及完整包根目录 README。

## 使用条件

桌面发行平台为 Windows x64。使用模型服务需要对应账户、可用模型与 API Key；服务可能收费，参考价用于估算，实际费用请核对服务商账单。

目标字数用于规划，完成进度受模型输出和任务额度影响。交付后请阅读并修订稿件；写入文件、执行命令和启动插件仍需相应授权。更多操作见[桌面指南](QUICKSTART.md)、[CLI 指南](CLI.md)与[数据运维](OPERATIONS.md)。
