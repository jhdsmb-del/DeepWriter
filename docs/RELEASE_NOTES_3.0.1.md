# DeepWriter 3.0.1

在桌面选好工作目录，试试：「找出铜钥匙第一次出现的地方，引用前后原文。后来是谁拿走了它？」Agent 可以先搜稿，再到对应行读上下文。文件开头无关的章节不必随每次读取一起发给模型。

终端也可以直接问：

```powershell
.\cli\deepwriter.cmd agent "在稿件里找到渡口交接的那一场，纸条上写了什么？请引用原文。" --work-dir ".\稿件"
```

**读到一半，接着读。** 即使一整段中文没有换行，Agent 也能从上页的最后一个字符之后继续读取。两次读取之间如果稿件被改过，工具会提示重新定位，避免把两个版本的段落拼到一起。
