# DeepWriter 4.0.0

## 从回复回到原文

把资料放进工作目录，问「两份交接记录的柜号相同吗？请给我原话。」点回复下方的**文件来源**，就能对照文件路径、行号和当时读到的段落。没读过的文件不会因为模型在回复里提到它就出现在这里。修改原文件后再打开旧回复，摘录仍是当时的版本。

在终端里输入 `/sources` 查看最近任务。脚本用 `deepwriter sources RUN --json`，无需重新调用模型。跨行的一句原话也可直接作为搜索词。

小窗口模型读长文件或 ZIP 条目时，DeepWriter 会按剩余空间分页，为下一页腾出位置；较早的只读结果仍可在文件来源里查看。

## 不必因为断流重写第一章

长文写到一半遇到网络中断，已经接受的章节会保留。打开**任务详情 → 活动 → 另存草稿**，可以先拿走已写好的部分，再恢复同一个任务；中断前屏幕上尚未写完的片段不会混进稿件。正文已写完、只是交付文件发生冲突时，恢复只处理文件，不重写正文。

```powershell
deepwriter export RUN --draft --output 半稿.md
deepwriter resume RUN
deepwriter export RUN --output 终稿.md
```

## 工具调用不再被误判为已经答完

修正了 Responses 接口的一种结束事件：模型已给出要调用的工具，DeepWriter 却提前结束对话。现在会先执行工具，等模型读过结果再回复。

## 读 PDF 不必等到最后一页

桌面读取 PDF 文字层时，到达本次摘录所需的长度就停止解析后续页面。页码保留；没有文字层的页不会被当作已读正文。取消读取也会回收正在解析的进程。
