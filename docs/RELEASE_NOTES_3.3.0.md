# DeepWriter 3.3.0

## 直接读工程包

把 ZIP 拖进 Agent，问：「先看目录，再读 README 和启动配置，告诉我怎么运行。」DeepWriter 在本机列目录、摘录可读内容；这次任务还能点名读取包内文件，不必先解压或把父目录授权给 Agent。大包分段读取，未读部分会标出来。若压缩包损坏，可以直接重新选择文件，已写的消息不会消失。

也可以直接给它 Excel、PowerPoint、代码、配置和日志。回答可定位到工作表单元格、幻灯片或包内文件。公式显示文件中保存的结果，不会重新计算。EPUB 按阅读顺序提取章节，桌面版可直接读工作目录中的 PDF 文字层。长文工作区的参考材料使用同一套解析。

## 联网使用自己的模型账户

输入框的地球图标跟随当前模型、接口与 Key。官方 DeepSeek 账户使用搜索和网页读取 API；支持原生搜索的 OpenAI Responses、Anthropic Messages 模型使用各自的检索服务。仅把本次检索词或目标公开网址发给供应商。单纯能够对话的接口不会被标为已联网，也不会转用免费的第三方搜索。

联网费用由供应商收取。DeepSeek 搜索与网页读取分别按有效请求计费；其他原生搜索可能同时产生搜索与模型 token 费用。关闭地球图标或使用 CLI 的 `--no-web`，新任务就不再获得网页工具。
