# DeepWriter 1.3.5

本次更新修复模型调用和普通对话的发送问题。

- 手动输入的模型 ID 不再因规格目录未收录而阻止发送。程序使用有限上下文预算，已知型号继续按模型规格运行。
- 上下文预览、任务快照和实际请求共用输出预算，小窗口模型也会保留输入空间。
- 无参考价格的型号会在发送前请求一次确认，不再无提示地进入等待处理。
- 调用失败时显示具体错误原因，不再出现空白“错误”；修改配置后可继续发送。
- 输入框支持发送按钮和回车提交；模型选择的悬停信息标明供应商与模型 ID。

## 使用

打开“设置 → 模型与接口”，填写 Base URL、API Key、API 格式和模型 ID 后保存。在输入框底部选择该模型，即可开始对话。

关闭旧程序后安装新版，或打开新版免安装文件。已有会话、模型配置和稿件保留，无需重新导入。
