# 末班渡船

一张五毛钱的旧渡票，两岸的末班铃声。在窗口前替检票员做一次选择：敲铃，还是把票送过河？

- **在桌面读路线**：打开 Galgame 工作室，点「导入项目」，选择 `last-ferry` 文件夹。打开剧情分支，查看两种选择各自通往哪个结局。选好 SDK，点「试玩原项目」即可上船。
- **用 Ren’Py 试玩**：在 Ren’Py 启动器的偏好设置中，将项目目录选为包含 `last-ferry` 的文件夹，选中项目并启动。回到主菜单再玩一次，就能读到另一面。
- **从命令行看分支**：在 DeepWriter 完整包解压目录运行 `.\cli\deepwriter.cmd galgame routes .\examples\last-ferry`。加 `--json` 可导出节点、选项和脚本行号。
